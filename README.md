# 2D OpenWorld SurvivalCraft
## 2D 오픈월드 생존제작 게임 :

![대체 텍스트](./Images/Shadow%20System.png)
![대체 텍스트](./Images/Inventory%20UI.png)

### 01. 게임 개요
 - 장르
   - 탑다운 2D 오픈 월드 게임
   - 생존 + 제작 + 탐험 + 전투 등의 요소가 있음
   - 싱글플레이 중심 (추후 멀티 확장?)

 - 핵심 기능
   - 자원 채집
   - 제작 시스템
   - 기지 건설
   - 생존 요소 (허기, 체력 ,온도 등)
   - 점진적 기술 발전
   - 절차 생성 맵

### 02. 세계관 & 콘셉트
 - 기본 설정
   - 추후 작성 예정

### 03. 핵심 게임 루프 (Core Loop)
 - 반복 동기
   - 탐험 -> 자원 획득 -> 제작 -> 기지 강화 -> 더 위험한 지역 탐험

### 04. 플레이어 시스템
 - 기본 스탯
   - 체력, 마력, 스태미나, 허기, 수분, 온도, 정신력 등 고려
 - 레벨 시스템
   - 채집, 전투, 제작 숙련도 등

### 05. 자원 & 채집 시스템
 - 기본 자원
   - 나무, 돌, 광석, 식량, 물 등
 - 희귀 자원
   - ... 
 - 채집 방식
   - 도구 필요 (도끼, 곡괭이)
   - 내구도 시스템
   - 자원 리스폰 시스템 (청크 기반 or 재생성?)
  
### 06. 제작 시스템
 - 인벤토리 즉시 제작
 - 제작대 필요 제작
   - 제작대 등급
 - 제작 카테고리
   - 장비 (무기, 도구, 방어구, 악세서리)
   - 건축 자재
   - 소비 아이템 (음식, 물약 등)
 - 확장 방향
   - 설계도
   - 기술 트리
   - 연구 시스템 등

### 07. 건설 시스템
 - 건설 요소
   - 바닥, 벽, 문, 가구, 창고
   - Grid 기반 설치
   - 스냅 시스템
   - 파괴 가능 구조물 등

### 08. 월드 구성
 - 바이옴
   - 초원, 숲, 사막, 설원, 늪지, 폐허 등
 - 위험도 단계
   - 고지역으로 갈수록 몬스터 강도&밀도 상승, 드롭 자원 희귀도 증가
 - 낮/밤 시스템
   - 밤에 강한 몬스터가 등장
   - 시야 감소
   - 기지 방어 시스템
  
### 09. 전투 시스템
 - 전투 방식
   - 실시간 타격
   - 히트박스 기반
   - 원거리/근거리 무기
 - 몬스터 유형
   - 일반 몬스터
   - 정예 몬스터
   - 보스 몬스터
   - 환경형 몬스터 (독 안개, 트랩, 미믹 등)
 - AI 패턴
   - 배회
   - 플레이어 추적
   - 집단 공격 (습격 + 기지 방어 연계)
   - 도망
  
### 10. 인벤토리 시스템
 - 기능
   - 슬롯 기반 인벤토리
   - 스탯 제한
   - 장비 슬롯
 - 확장 요소
   - 가방 제작 시 슬롯 증가
   - 무게 시스템
  
### 11. 그래픽 방향
 - 스타일
   - 픽셀 도트 그래픽
   - 16x16 또는 32x32 에셋 사용
 - 카메라는 탑다운 방식

### 12. 기술적 구조 설계
 - 핵심 시스템 구현 필요
 - 데이터 관리
   - ScriptableObject 기반 아이템 데이터
   - 저장 시스템

### 13. 저장 시스템
 - 저장 대상
   - 플레이어 위치, 인벤토리, 건설 구조물, 월드 상태, 몬스터 상태, 이벤트 상태 등
 - 저장 방식
   - 일정 시간 자동 저장
   - 침대에서 수동 저장
   - 게임 종료 시 저장 

### 14. 확장 가능 콘텐츠
 - 농사 시스템
 - 동물(펫) 길들이기
 - NPC 마을
 - 퀘스트 시스템
 - 던전 인스턴스
 - 계절(날씨) 시스템
 - 자동화 기계
